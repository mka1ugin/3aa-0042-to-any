## 📥 Запуск

Готовый файл лежит в [релизах](https://github.com/mka1ugin/3aa-0042-to-any/releases/latest): `3AA_0042_to_any.exe`.

Python на компьютере не нужен. Эталонный заголовок прошивки вшит в программу, отдельный файл-образец не требуется. Откройте exe, выберите SGO и сохраните результат в новое место.

Подходит только прошивка с заголовком **3AA698109__0042**. Другие версии ABS программа не откроет: адреса таблицы констант у них другие. Уже отредактированные варианты этой же версии открываются, контрольная сумма файла при проверке заголовка не учитывается.

## ✨ Что делает

1. Читает блок №1, память `0x004000–0x07FFFF`. В SGO эти данные хранятся как XOR `0xFF`.
2. Показывает таблицу констант: 43 записи по 22 байта, смещение в образе `0x03A31C–0x03A6CD`.
3. После каждой правки пересчитывает контрольную сумму bin-образа, слово по смещению `0x0004`.
4. При сохранении заново считает контрольную сумму блока №1 и всего файла SGO.

Сохранение без правок даёт тот же файл байт в байт.

## 🖱 Как править

| | |
| --- | --- |
| 📋 Список | двойной щелчок, F2 или Enter, значение выбирается из списка |
| 🔢 Число | мощность, масса и объём вводятся десятичным числом |
| 🔒 Закрыто | «2й байт кодировки», «Байт 9» и «Байт 21» не меняются |
| ↩ Отмена | Ctrl+Z и «Отменить все правки» |
| 💾 Запись | «Сохранить SGO...» спрашивает, куда положить файл |

Объём двигателя задаётся в кубических сантиметрах и округляется до 100. `0x0E` на экране — это `1400`, ввод `1450` сохранится как `1500`. Мощность и масса хранятся как big-endian.

## 🧩 Поля записи

| Поле | Ввод |
| --- | --- |
| 🔐 2й байт кодировки | только чтение |
| Байт 1 | `00` `01` `02` |
| Байт 2 | `01` … `0A` |
| Байт 3 | `00` … `03` |
| 🛑 Тормоза 1 и Тормоза 2 | `0C` `0D` `0E` |
| ⚙ Тип трансмиссии | механика, автомат или DSG, 2WD или 4WD |
| Байт 7 | `03` `05` |
| 🌍 Вариант рынка | `AA` `BB` |
| Байт 9 | всегда `00`, правка закрыта |
| ⚡ Номинальная мощность, кВт | целое, big-endian |
| 📉 Минимальная мощность по CAN, кВт | целое, big-endian |
| 📈 Максимальная мощность по CAN, кВт | целое, big-endian |
| 🏎 Объём двигателя | см³, шаг 100 |
| Байт 17 | `02` `05` |
| ⚖ Масса автомобиля, кг | целое, big-endian |
| Байт 20 | `00` … `06` |
| Байт 21 | всегда `00`, правка закрыта |

## 🚗 Чтобы ABS принял мотор

Таблица должна совпасть с тем, что мотор и панель передают по CAN.

| | Сигнал | Условие |
| --- | --- | --- |
| ⚙ | `MO2_Getr_Code`, сообщение `mMotor_2`, ID `0x288` | DSG 2WD = `0x0B`, механика 4WD = `0x0F` |
| 🌍 | `KO3_Land`, сообщение `mKombi_3`, ID `0x520` | `AA`, если код земли `0, 1, 4, 6, 7`; `BB`, если `2, 3, 5` |
| 🏎 | `MFN_Hubraum`, сообщение `mMotor_Flexia_neu`, ID `0x580` | объём двигателя |
| ⚡ | `MFN_Motorleistung`, то же сообщение | мощность должна попасть между минимумом и максимумом по CAN |

## 🛠 Сборка exe

Нужен Python 3.12. Из каталога проекта:

```bat
build_exe.bat
```

Скрипт ставит PyInstaller и собирает `dist\3AA_0042_to_any.exe`. Окно без консоли, один файл.

Проверка логики без интерфейса:

```bat
python -m unittest test_sgo.py
```
