## 📥 Запуск

Готовый файл лежит в [релизах](https://github.com/mka1ugin/vag-trw450-to-any/releases/latest): `VAG_TRW450_to_any.exe`.

Python на компьютере не нужен. Эталонный заголовок прошивки вшит в программу, отдельный файл-образец не требуется. Откройте exe, выберите SGO и сохраните результат в новое место.

Подходят прошивки с заголовком **3AA698109__0042** (таблица `0x03A31C`, 43 записи), **3AA614109__0023** (`0x05D0A0`, 43 записи), **3AA614109__0061** (`0x03ABBC`, 16 записей), **5N0614109__0023** (`0x03956C`, 25 записей), **5N0614109__0161** (`0x03D934`, 25 записей), **8U0614109__0406** (`0x03D8D0`, 28 записей) и **3C0698109__0017** (`0x077AEC`, 55 записей по 20 байт, один блок №0). У первых шести колонки одинаковые. Другие версии ABS программа не откроет. Уже отредактированные варианты этих версий открываются: контрольная сумма файла при проверке заголовка не учитывается.

**Работа с прошивкой 3C0 не гарантируется.** У `3C0698109__0017` другой расчёт контрольной суммы BIN: она охватывает не весь блок, а только диапазон адресов из заголовка образа, `0x4000`–`0xE800`. Таблица констант лежит дальше. Программа открывает файл и считает суммы по этому правилу, но результат нужно проверять самостоятельно.

## ✨ Что делает

1. Читает блок №1, память `0x004000–0x07FFFF`. В SGO эти данные хранятся как XOR `0xFF`.
2. Показывает таблицу констант, записи по 22 байта. У `3AA …0042` она с `0x03A31C` (43 записи), у `3AA …0023` — с `0x05D0A0` (43), у `3AA …0061` — с `0x03ABBC` (16), у `5N0 …0023` — с `0x03956C` (25), у `5N0 …0161` — с `0x03D934` (25), у `8U0 …0406` — с `0x03D8D0` (28).
3. После каждой правки пересчитывает контрольную сумму bin-образа, слово по смещению `0x0004`.
4. При сохранении заново считает контрольную сумму блока №1 и всего файла SGO.

Сохранение без правок даёт тот же файл байт в байт.

## 🖱 Как править

| | |
| --- | --- |
| 📋 Список | выпадающий список. В нём только значения из таблицы этой прошивки |
| 🔢 Число | мощность, масса и объём вводятся десятичным числом, Enter записывает ячейку |
| 🔒 Закрыто | «2й байт кодировки», «Байт 9» и «Байт 21» не меняются |
| ↩ Отмена | Ctrl+Z и «Отменить все правки» |
| 💾 Запись | «Сохранить SGO...» спрашивает, куда положить файл |
| 📖 Справка | меню «Справка» показывает `HELP.md` |

Объём двигателя задаётся в кубических сантиметрах и округляется до 100. `0x0E` на экране — это `1400`, ввод `1450` сохранится как `1500`. Мощность и масса хранятся как big-endian.

## 🚗 Чтобы ABS принял мотор

Таблица должна совпасть с тем, что мотор и панель передают по CAN.

| | Сигнал | Условие |
| --- | --- | --- |
| ⚙ | `MO2_Getr_Code`, сообщение `mMotor_2`, ID `0x288` | DSG 2WD = `0x0B`, механика 4WD = `0x0F` |
| 🌍 | `KO3_Land`, сообщение `mKombi_3`, ID `0x520` | `AA`, если код земли `0, 1, 4, 6, 7`; `BB`, если `2, 3, 5` |
| 🏎 | `MFN_Hubraum`, сообщение `mMotor_Flexia_neu`, ID `0x580` | объём двигателя |
| ⚡ | `MFN_Motorleistung`, то же сообщение | мощность должна попасть между минимумом и максимумом по CAN |

## 🛠 Сборка exe

Интерфейс на Flet. Нужен Python 3.12. Из каталога проекта:

```bat
build_exe.bat
```

Скрипт ставит Flet и собирает `dist\VAG_TRW450_to_any.exe`. Окно без консоли, один файл. Текст справки берётся из `HELP.md`.

Проверка логики без интерфейса:

```bat
python -m unittest test_sgo.py
```
