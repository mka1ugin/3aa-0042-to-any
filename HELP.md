# VAG TRW450 to any

Редактор таблицы констант ABS TRW 450 в контейнере SGO. Меняет кодировку под мотор и трансмиссию и сам пересчитывает контрольные суммы.

Подходят прошивки с заголовком **3AA698109__0042**, **3AA614109__0023**, **3AA614109__0061**, **5N0614109__0023**, **5N0614109__0161**, **8U0614109__0406** и **3C0698109__0017**. Другие версии программа не откроет. Уже отредактированные варианты этих версий открываются: контрольная сумма файла при проверке заголовка не учитывается.

У **3C0698109__0017** в контейнере один блок, №0. Запись в таблице короче: 20 байт, с `0x077AEC`, 55 записей. Нет старых байта 7 и байта 9. Номинальная мощность — один байт. Байт 8 и байт 19 всегда `00`.

**Работа с прошивкой 3C0 не гарантируется.** У `3C0698109__0017` другой расчёт контрольной суммы BIN: она охватывает не весь блок, а только диапазон адресов из заголовка образа, `0x4000`–`0xE800`. Таблица констант лежит дальше. Программа открывает файл и считает суммы по этому правилу, но результат нужно проверять самостоятельно.

## Как править

1. **Файл → Открыть SGO...** Читается блок №1, память `0x004000–0x07FFFF`. В SGO эти данные хранятся как XOR `0xFF`.
2. В таблице каждая строка — запись из 22 байт. Списки содержат только те значения, которые уже есть в таблице открытого файла.
3. Числа (мощность, масса, объём) вводятся десятичными. Enter или уход из ячейки записывает значение.
4. **Файл → Сохранить SGO...** спрашивает, куда положить файл. Перед записью пересчитываются контрольная сумма блока №1 и всего файла SGO.
5. **Правка → Отменить** (Ctrl+Z) возвращает одну ячейку. **Отменить все правки** возвращает таблицу к последнему открытому или сохранённому состоянию.

Закрытые поля не меняются: «2й байт кодировки», «Байт 9» и «Байт 21».

Объём двигателя задаётся в кубических сантиметрах и округляется до 100. `0x0E` на экране — это `1400`, ввод `1450` сохранится как `1500`. Мощность и масса хранятся как big-endian.

Изменённая строка подсвечивается. Сохранение без правок даёт тот же файл байт в байт.

## Поля записи

У подключённых прошивок запись одинаковая. У другой версии набор колонок задаётся вместе с профилем.

| Поле | Ввод |
| --- | --- |
| 2й байт кодировки | только чтение, должен совпасть со вторым байтом длинной кодировки |
| Байт 1, Байт 2, Байт 3 | индекс калибровочного пакета, список из файла |
| Тормоза 1 и Тормоза 2 | класс кривой скорости колеса, список из файла |
| Тип трансмиссии | список из файла. Известные коды подписаны |
| Байт 7 | индекс калибровочного пакета, список из файла |
| Вариант рынка | список из файла |
| Байт 9 | всегда `00`, правка закрыта |
| Номинальная мощность, кВт | целое, big-endian |
| Мощность с CAN min, кВт | целое, big-endian |
| Мощность с CAN max, кВт | целое, big-endian |
| Объём двигателя | см³, шаг 100 |
| Байт 17 | индекс калибровочного пакета, список из файла |
| Масса автомобиля, кг | целое, big-endian |
| Пороги вмешательства ESP | список из файла |
| Байт 21 | всегда `00`, правка закрыта |

Подписи трансмиссии: `00` механика 2WD, `10` автомат 2WD, `40` DSG 2WD, `02` механика 4WD, `12` автомат 4WD, `42` DSG 4WD. Незнакомый код показывается как hex.

## Чтобы ABS принял мотор

Таблица должна совпасть с тем, что мотор и панель передают по CAN.

| Сигнал | Условие |
| --- | --- |
| `MO2_Getr_Code`, сообщение `mMotor_2`, ID `0x288` | DSG 2WD = `0x0B`, механика 4WD = `0x0F` |
| `KO3_Land`, сообщение `mKombi_3`, ID `0x520` | `AA`, если код земли `0, 1, 4, 6, 7`; `BB`, если `2, 3, 5` |
| `MFN_Hubraum`, сообщение `mMotor_Flexia_neu`, ID `0x580` | объём двигателя |
| `MFN_Motorleistung`, то же сообщение | мощность должна попасть между минимумом и максимумом по CAN |

## Контрольные суммы

Над таблицей три суммы. Пока файл не меняли, у каждой подпись «без изменений».

| На экране | Что это |
| --- | --- |
| CRC TRW | слово bin-образа по смещению `0x0004`. Считается после каждой правки |
| CRC SGO block | сумма блока №1. Записывается при сохранении |
| CRC SGO file | сумма всего контейнера SGO. Записывается при сохранении |

Если в открытом файле сумма не сходится, программа предупредит. При сохранении все три будут пересчитаны.
